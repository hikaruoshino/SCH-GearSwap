# SCH-GearSwap（学者 GearSwap / Melton6 対応版）

**ファイナルファンタジーXI（Windower 4用） 学者の GearSwap 一式。[WindowerでFF11ライフ（greeds.net）](https://greeds.net/gearswap-code-list/) の GearSwap コードを元に、震天動地の章・6連携メルトン向けに手を入れたものです。**

自動キャストアドオン **[Melton6](https://github.com/hikaruoshino/Melton6)**（学者の震天6連携 → メルトンMB をマクロ1回で実行）を、すぐに使えるようにするために公開しています。作者が実際に使っているファイルそのものです。

## 🌟 SCH.lua の特徴（元との違い）

### 1. 黒魔法の FC で武器を持ち替えない（`FC.Black` / `FC.BlackSurplus`）
* 黒のグリモア・黒の補遺・震天動地の章の間は、精霊魔法とメルトンの詠唱前の装備を **`sets.precast.FC.Black`** にします。
* 元は FC のたびに両手棍（ムサ）に持ち替えるため、見た目が切り替わって点滅していました。`FC.Black` は片手棍＋盾（マフィックカジェル＋チャンターシールド）で、震天の装備と同じ武器種にそろえています。
* **サポ赤のときは、ジョブ特性ファストキャストをサポのレベルから計算**します（Lv15 で10%、Lv35 で15%、Lv55 で20%）。装備の FC と足して上限80%に届くなら、耳と指をモクシャ装備にした **`FC.BlackSurplus`** を使います。
* サポが Lv0 になるシェオル ジェールなどでは、装備だけで FC 80% の `FC.Black` を使います。
* インパクトは専用の FC セットを崩さないよう、対象外です。

### 2. 震天動地の章の装備を最優先にする
* 震天動地の章の間は、腰の帯の自動判定をせず、**`sets.buff['震天動地の章']` を最優先で装備**します。
* 震天の魔法は連携を作るためのものなので、ダメージを抑えた装備のまま撃てます。

### 3. 属性帯とオルペウスサッシュの自動選択
* ダメージを与える精霊魔法（**計略魔法を含む**）とメルトンで、**属性帯・八輪の帯（天候・曜日・陣）とオルペウスサッシュ（敵との距離）のうち、効果が大きいほう**を自動で装備します。
* 元は計略魔法を除く精霊魔法で、八輪の帯だけを判定していました。
* 精霊弱体（バーンなど）とインパクトは、命中重視のセットを崩さないよう着替えません。
* 回復魔法は、元と同じく天候・曜日で効果がプラスのときだけ属性帯にします。

### 4. そのほかの変更
* 武器の候補を変更しました（メイン: ムサ、ブンジロッド、マフィックカジェル、マレヴォレンス、デイブレイクワンド、ハーミットワンド / サブ: コーンスー、アムラピシールド、玄冥盾、エンキストラップ、カルミナス、チャンターシールド）。オパショーロは外しています。
* ロックスタイルの「通常」の武器を、ムサ＋コーンスーにしました。ロックスタイル番号が未設定のときは 100 を使います。
* Shift+F7（OffenseMode の切り替え）の割り当てを外しています。
* キャスティングモードに `Normal` / `MB` を追加しています。同梱の `SCH_gear.lua` は、精霊魔法をいつも MB で撃つ前提で、**MB 用の装備を `sets.midcast['精霊魔法']` に入れています**。そのため `.MB` のセットは作っておらず、`MB` に切り替えても装備は変わりません。通常と MB で装備を分けたい場合は、`sets.midcast['精霊魔法'].MB` を書けば `MB` のときに切り替わります。
* エラーメッセージを日本語にしました。

## 👗 SCH_gear.lua の特徴（元との違い）

* **追加したセット**
  * `sets.precast.FC.Black`: 黒魔法用の FC セット（装備の FC 80%、片手棍＋盾）。
  * `sets.precast.FC.BlackSurplus`: FC が余るとき用。耳をディグニタリピアス、指をシーリチリング+1 ×2 にしたもの（装備の FC 72%）。
  * `fc_gear_value = {Black = 80, BlackSurplus = 72}`: 上の2つの装備の FC（%）。`SCH.lua` がサポ赤の特性 FC と足して、どちらを使うか決めます。**装備を変えたら、ここの数字も直してください。**
  * `sets.precast.WS["イオリアンエッジ"]`、`sets.precast.WS["ミルキル"]`: 片手剣・片手棍の WS。
  * `sets.idle.seirei` / `sets.idle.keiryaku` / `sets.idle.modoshi`: 武器だけを持ち替えるセット（`SCH.lua` からは呼ばず、手動で装備する用）。
* **震天動地の章のセット**: 元は両手棍（マリグナスポール）でしたが、FC と同じ片手棍＋盾（マフィックカジェル＋チャンターシールド）にしています。連携を作るだけなのでダメージは抑え、敵に TP を与えないモクシャ（ディグニタリピアス、シーリチリング+1 ×2）を入れています。
* **精霊魔法のセット**: `sets.midcast['精霊魔法']` は、MB 用の装備で組んでいます（精霊魔法はいつも MB を狙う前提）。
* **最初に持つ武器**: ムサ＋コーンスー。
* **装備の中身**: すべて作者の所持装備に合わせています。**自分の装備に書き換えてから使ってください。**

## 🌦️ weather_obi.lua（v3）の特徴（元との違い）

* **判定の方法**: 元は天候の名前（「熱波」など）を文字で比べていました。v3 では GearSwap が用意する**天候の属性・強さ・曜日の属性**で判定します。学者の陣・陣IIも、GearSwap 側で天候として扱われるので、そのまま反映されます。
* **効果を%で計算**: 同属性の天候 +10%（強天候 +25%）、同属性の曜日 +10%、反属性はマイナスとして合計し、**プラスのときだけ帯を装備**します。
* **オルペウスサッシュ**: 敵との距離から効果（1.93以内で+15%、13以上で+1%、その間は距離に比例）を計算する `get_elemental_waist` を追加しました。属性帯とどちらが得かを比べます。
* **個別の属性帯**: 持っている個別の帯（火輪の帯など）を、八輪の帯より優先します。作者は火輪・風輪・闇輪の帯を持っている設定なので、**`elemental_obi` を自分の持ち物に合わせて書き換えてください。**
* 元と同じ名前の `get_hachirin` も残しているので、ほかのジョブのファイルもそのまま動きます。

## 📂 インストール

1. greeds.net の GearSwap コード一式（`user-globals.lua` など）を入れておきます。導入方法は [配布ページ](https://greeds.net/gearswap-code-list/) を確認してください。
2. このリポジトリを **Code → Download ZIP** でダウンロードし、解凍します。
3. ファイルを置きます（同じ名前のファイルは上書き。上書きの前に元のファイルを退避しておくと安心です）。
   ```
   GearSwap/
     data/
       SCH.lua                 ← このリポジトリの SCH.lua
       user-globals.lua        ← greeds.net 版のまま
       キャラクター名/
         SCH_gear.lua          ← このリポジトリの SCH_gear.lua
         weather_obi.lua       ← このリポジトリの weather_obi.lua
   ```
4. 次の3か所を、自分に合わせて書き換えます。
   * `SCH_gear.lua` の装備（持っていない装備は、持っているものに置き換える）
   * `SCH_gear.lua` の `fc_gear_value` と、ロックスタイル番号（`lockstyleset` など）
   * `weather_obi.lua` の `elemental_obi`（持っている個別の属性帯）
5. ゲーム内で `//gs reload` を実行します。`//gs showswaps` を ON にすると、着替えをチャットで確認できます。
